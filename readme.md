
# SkillSwap 🎯

SkillSwap is an interactive skill-exchange platform where people can connect with others to teach and learn new skills.

The goal of SkillSwap is to make learning easier by allowing users to share their knowledge and explore new interests.

## ✨ Features

- User registration and login interface
- Explore different skills
- Search for skills
- Filter skills by category
- Sort available skills
- View skill and user profile details
- Send demo connection requests
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Web Crypto API

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you haven't already.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The website will open in your browser.

## 🔐 Authentication Notice

This project currently uses a front-end demonstration of authentication. Account information is stored locally in the browser. It does not use a secure backend authentication system.

Do not use real passwords or sensitive personal information.
